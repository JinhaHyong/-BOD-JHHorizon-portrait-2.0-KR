# JHnode 초상화·폰트 교체 프로그램 — PySide6 전환판

기존 단일 파일 프로그램을 PySide6로 전환하고 역할별로 코드를 분리한 JHnode 버전입니다. 화면의 버전 표기 3.0도 유지했습니다.

프로그램과 창 제목의 명칭은 **JHnode**입니다. 기존 설정·다운로드한 폰트·미리보기·최근 초상화 설정을 계속 사용하도록 사용자 저장 경로는 이전 `JHHorizon/PortraitManager` 경로를 유지합니다.

EXE 빌드는 `BUILD-EXE.md`를 참고하세요. 배포받는 사람은 Python 설치 없이 `JHnode` 폴더 전체를 압축 해제해 실행합니다. Python 3.12 x64로 빌드한 EXE의 자체 검사 8개 항목을 Windows에서 통과했습니다. Python이 없는 Windows Sandbox 검사와 실제 게임 적용 확인은 별도 단계입니다.

단일 EXE도 지원합니다. `build_exe.ps1 -Mode single`로 만들면 `dist/JHnode.exe` 하나로 실행하며 외부 `_internal` 폴더가 필요하지 않습니다. 새 초상화 기본 폴더는 EXE 옆을 기준으로 하고, 설정·다운로드 폰트는 기존 사용자 경로를 유지합니다. 단일형의 경로 회귀 검사를 포함한 **82개 테스트**가 통과했으며, Python이 없는 Sandbox에서 EXE 하나만 둔 폴더로 **8개 자체 검사를 두 번 통과**했습니다. 두 실행 모두 임시 압축 해제 폴더가 종료 후 정리되는 것을 확인했습니다. 함께 내보내는 안내·고지문·라이선스 문서는 배포 시 보관하세요.

## 배포 전 오류 개선

사진 선택은 마우스·방향키·필터 변경 모두 Qt의 실제 선택 상태를 기준으로 처리합니다. 선택 테두리·미리보기·교체 대상이 함께 바뀌며, 교체 직전에도 세 경로가 일치하는지 확인하여 다르면 쓰기를 막고 다시 맞춥니다. 같은 사진을 유지하는 검색에서는 불필요한 미리보기 재로딩을 하지 않습니다.

같은 사용자·같은 설정 경로의 JHnode는 한 번만 실행됩니다. 다시 실행하면 기존 창을 복원하고 앞으로 가져옵니다. 동시에 시작하거나 이전 프로그램이 비정상 종료한 경우도 잠금 소유권을 확인합니다. 설정은 짧은 쓰기 잠금 안에서 최신 디스크 값과 병합하고 원자적으로 저장하며, 저장 직전의 유효 값은 `settings.json.bak`에 보관합니다. 본 설정이 손상되거나 사라졌으면 복구본을 읽습니다. 기존 버전으로 켜 둔 창은 모두 종료하고 새 버전으로 다시 실행해야 새 중복 실행 방지가 적용됩니다.

폰트 파일을 선택하면 가족명뿐 아니라 스타일명·기본 굵기·기울임을 함께 기억합니다. 글자 미리보기·내보내기·다시 열기·최근 설정·일괄 적용에서도 같은 얼굴을 사용하며 굵게·기울임 체크 해제는 선택 파일의 원래 스타일로 돌아갑니다. 같은 가족을 단순 선택했을 때 마지막으로 내려받은 다른 굵기를 잘못 연결하지 않습니다.

폰트 적용 위치는 저장된 경로도 검은사막 실행 파일이 있는지 확인합니다. 예전 빈 설치 폴더만 남았으면 위치 선택을 다시 요청하고, 선택한 위치와 실제 파일 복사 직전에도 검사합니다. 내 PC·온라인 탭 모두 하단 폰트 적용 버튼 위의 안내/선택 이름 문구를 없애고 버튼을 세로 중앙에 배치했습니다. 화면 크기는 기존 830×910을 유지합니다.

이 변경 후 임시 사진·임시 설정·가짜 게임 설치 폴더에서 기존 및 추가 회귀 테스트 **79개 모두 통과**했습니다. 실제 게임 파일과 사용자 설정은 테스트에서 변경하지 않았습니다. EXE에서도 같은 방식으로 기본 기능·리소스·글꼴·백업·설정 보호를 확인했으며 실제 게임 실행 후 적용 여부는 별도 확인 대상입니다.

## 실행

Python 3.10 이상이 필요합니다. Python 3.12.10, PySide6 6.11.2, Pillow 12.3.0 환경에서 확인했습니다.

이 폴더에서 다음 명령을 실행합니다.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

설치가 끝나면 `run.bat`을 더블 클릭해 실행할 수 있습니다. 이 파일은 폴더 안의 `.venv`를 우선 사용합니다. 이미 의존성이 설치된 Python을 사용한다면 `python main.py`로 실행할 수 있습니다. 다른 폴더에서 실행할 때도 `main.py`의 전체 경로를 지정하면 됩니다. 리소스는 프로그램 위치를 기준으로 찾습니다.

## 사용과 설정

- 초상화 기본 위치는 Windows의 문서 폴더 아래 `Black Desert/FaceTexture`입니다. 폴더 선택 버튼으로 변경할 수 있습니다.
- 새 초상화는 이 프로그램 폴더의 `새 초상화`에서 기본으로 찾습니다. 폴더 선택 버튼으로 다른 위치를 지정할 수 있습니다.
- 현재·새 초상화 목록과 두 미리보기는 같은 제목 높이·여백·테두리를 사용합니다. 검색창 유무에 관계없이 양쪽 목록의 첫 줄이 같은 높이에서 시작하며, 썸네일 간격과 선택 테두리 두께도 통일했습니다. 두 미리보기 제목은 가운데 정렬이며, 목록의 썸네일 묶음도 위쪽을 유지하면서 좌우 가운데에 배치합니다. 이미지 이름 검색창은 새 초상화 목록 제목 바로 옆에서 오른쪽 끝까지 남는 너비를 채웁니다.
- 이미지 이름 검색은 폴더를 읽을 때 준비한 썸네일을 재사용하고 메모리의 파일 이름만 비교합니다. 입력할 때마다 BMP를 다시 검사하거나 이미지를 읽고 위젯을 새로 만들지 않습니다. 한글은 확정된 글자와 조합 중인 마지막 글자를 함께 검색에 반영합니다. 예를 들어 `매구`를 입력하면 마지막 `구`가 조합 중이어도 그 전체 이름으로 걸러지므로 스페이스나 Enter를 추가로 누를 필요가 없습니다. 입력기를 강제로 확정하지 않고 기본 한글 조합·삭제·붙여넣기 동작을 유지합니다. 검색 결과가 같으면 배치도 다시 만들지 않습니다. 검색에서 빠진 초상화의 선택과 편집 아이콘은 해제합니다. 텍스트를 적용한 뒤에는 해당 썸네일만 갱신합니다. 폴더를 다시 선택하면 파일 목록을 다시 읽고, 초상화를 교체하면 바뀐 파일만 갱신합니다.
- 실제 BMP 형식이고 가로 624, 세로 804픽셀 이하인 이미지만 목록에 표시합니다. 규격을 넘는 이미지를 자동으로 축소하여 저장하지 않습니다.
- 폰트는 Windows 설치 폰트 폴더에서 읽습니다. 목록 옆 `+`로 동봉된 `resources/fonts` 등 다른 폴더를 추가할 수 있습니다.
- 폰트의 기본 적용 위치는 `C:/Pearlabyss/BlackDesert/prestringtable/font/pearl.ttf`입니다. 기억한 게임 설치 폴더가 없으면 적용할 때 바탕화면의 게임 바로가기나 설치 폴더를 선택합니다.
- 언어, 초상화 폴더, 추가 폰트 폴더, 폰트 적용 위치는 `%LOCALAPPDATA%/JHHorizon/PortraitManager/settings.json`에 저장합니다. 게임 설치 위치는 폰트 창 하단의 **위치 변경**으로 다시 지정할 수 있습니다.
- 각 창의 언어는 함께 바뀌며, 동일 기능 창은 하나씩 재사용합니다.
- 초상화 교체 창 하단의 언어 버튼 오른쪽에서 해·달 아이콘을 누르면 라이트·다크 모드를 전환합니다. **해 아이콘은 현재 라이트 모드**, **달 아이콘은 현재 다크 모드**를 뜻합니다. 배경·목록·입력칸·글자색을 함께 바꾸고 편집창·최근 설정·온라인 폰트 창에도 같은 모드를 적용합니다. 선택은 기존 설정 파일의 `theme_mode`에 저장하므로 다시 실행하거나 EXE를 바꿔도 같은 사용자 계정에서 유지됩니다. 초상화 이미지와 편집한 글자·박스의 실제 색상, 폰트 카드의 색상 비교는 테마에 따라 바꾸지 않습니다. 목록 썸네일과 큰 미리보기의 화면용 여백은 투명하게 처리하므로 다크 모드에서는 어두운 배경이, 라이트 모드에서는 밝은 배경이 보입니다. 이 여백은 원본 사진이나 저장·교체할 BMP에 추가하지 않습니다.
- 화면을 열거나 폰트를 미리 보는 것만으로 게임 폴더를 생성하거나 수정하지 않습니다.

## 폰트 변경 화면

프로그램을 실행하면 별도의 기능 선택 화면 없이 초상화 교체 창이 바로 열립니다. 하단 **한국어 · EN** 오른쪽의 **Aa 아이콘**을 누르면 폰트 변경 창이 열립니다. 아이콘에 마우스를 올리면 현재 언어에 맞춰 **폰트 변경 / Change Font** 안내가 표시됩니다. 폰트 창은 처음 누를 때 만들며, 이미 열려 있으면 같은 창을 앞으로 가져오고 최소화되었으면 복원합니다. 폰트 창을 닫았다가 다시 열어도 같은 창을 재사용합니다. 초상화 창을 닫으면 폰트 창도 함께 닫으며 진행 중인 온라인 작업을 정리합니다. 해·달 버튼은 Aa 아이콘 오른쪽에 유지합니다. 이번 변경은 요청에 따라 실행 검증하지 않았습니다.

폰트 창은 **내 PC 폰트 / 온라인 폰트** 탭으로 나뉘며, 두 탭 모두 왼쪽은 검색과 목록, 오른쪽은 선택한 폰트와 미리보기입니다. 창 크기를 조절하고 목록·미리보기 사이의 경계를 끌어 너비를 조절할 수 있습니다. 기존 초상화 창과 공통 라이트·다크 팔레트를 사용합니다.

**내 PC 폰트**에서는 폰트 이름을 검색하고 **+ 폰트 추가**, **새로고침**으로 파일을 관리합니다. **폰트 추가**는 폴더 대신 TTF 파일을 직접 선택하며 여러 파일을 한 번에 추가할 수 있습니다. 실제 TrueType 형식을 확인한 파일만 목록에 추가하고 중복은 합칩니다. 파일 경로는 `extra_font_files` 설정에 기억하여 다음 실행에도 불러옵니다. 원본 파일을 이동하거나 삭제하면 해당 파일은 표시하지 않으며, 기존에 기억한 추가 폴더는 계속 읽습니다. 추가한 첫 폰트를 자동으로 선택하고 검색을 비워 바로 확인할 수 있게 합니다. Windows 폰트 설치나 게임 파일 교체는 이 단계에서 진행하지 않습니다. 오른쪽에 폰트 이름과 로컬·다운로드 여부를 표시하며, 미리보기 문구를 입력하면 밝은 배경·어두운 배경·금색·하늘색 카드에 한 줄로 보여줍니다. 입력한 내용은 HTML로 해석하지 않고 그대로 그립니다.

**온라인 폰트**에서는 기존 고정 문구 이미지를 재사용하고, 선택한 굵기의 다운로드 여부를 표시합니다. 온라인 탭을 열 때 온라인 패널을 준비하고 목록을 갱신하며, 보이는 동안 5분마다 최신 목록을 확인합니다. 새 폰트의 미리보기 생성 안내도 이 탭에서 표시합니다. 아직 다운로드하지 않은 폰트는 하단의 적용 버튼이 비활성화되며 다운로드가 끝나면 바로 적용할 수 있습니다. 다운로드만으로 게임 파일을 변경하지 않습니다. 탭을 바꾸면 활성 탭에서 선택한 폰트를 적용 대상으로 사용합니다.

하단은 두 탭이 공유하는 적용 영역입니다. 현재 **검은사막 설치 위치**, 폴더 확인 상태와 **위치 변경**, 선택한 폰트와 **폰트 적용** 버튼을 표시합니다. 긴 설치 경로는 가운데를 줄여 표시하고 마우스를 대면 전체 경로를 보여줍니다. 위치 변경은 경로만 저장하며, 실제 폰트 복사와 백업은 **폰트 적용**을 눌렀을 때 진행합니다. 위치를 찾지 못하면 기존 바로가기·설치 폴더 선택 기능을 사용합니다.

텍스트 편집창에서는 공통 온라인 패널을 별도 선택창으로 계속 사용합니다. 폰트 창을 닫으면 진행 중인 온라인 작업을 정리하고 다음에 열 때 다시 사용할 수 있습니다. 이번 UI 개편은 요청에 따라 실행 검증하지 않았습니다.

## 바로가기로 폰트 적용 위치 찾기

**폰트 적용**을 눌렀을 때 저장된 설치 폴더나 기본 설치 폴더가 없으면 **바탕화면 바로가기 선택**과 **설치 폴더 직접 선택**을 표시합니다. 바로가기 선택창은 Windows의 개인 바탕화면과 공용 바탕화면(`%PUBLIC%/Desktop`, 기본 `C:/Users/Public/Desktop`)의 바로가기를 한 목록에 표시합니다. OneDrive 등으로 이동한 개인 바탕화면도 Windows에서 알려준 경로로 읽고, 각 항목에는 개인·공용 구분을 붙입니다. 검은사막 이름의 바로가기를 위에 표시하며, 한글 이름 검색과 더블 클릭 선택을 지원합니다. **다른 파일 찾기**로 바탕화면 밖에 있는 바로가기나 실행 파일도 선택할 수 있습니다. 검은사막 실행 바로가기 `.lnk`, Steam 실행 바로가기 `.url`, 또는 게임 실행 파일 `.exe`를 선택할 수 있습니다.

일반 바로가기는 Windows의 바로가기 정보에서 대상 파일과 작업 폴더를 읽습니다. Steam 바로가기는 해당 게임 ID의 로컬 설치 기록과 Steam 라이브러리 목록을 읽어 설치 폴더를 찾습니다. 전체 드라이브를 검색하거나 바로가기·게임·Steam을 실행하지 않습니다. 확인은 백그라운드에서 진행합니다. 바로가기 정보 읽기에는 Windows에 기본 제공되는 PowerShell과 Windows Script Host를 사용하며 추가 Python 패키지는 필요하지 않습니다.

찾은 폴더에 `BlackDesertLauncher.exe` 또는 검은사막 클라이언트 실행 파일이 있는지 확인한 뒤 기존 방식으로 `prestringtable/font/pearl.ttf`에 폰트를 적용하고 이전 파일을 백업합니다. 설치 위치가 여러 개라면 적용할 위치를 선택합니다. 적용에 성공한 위치는 기존 `font_folder` 설정에 저장합니다. 찾지 못했거나 취소하면 폰트를 복사하지 않습니다. 웹사이트 주소만 가리키는 바로가기에서는 실제 설치 위치를 알 수 없으므로 실행 바로가기나 설치 폴더를 선택해야 합니다.

Windows 바로가기의 대상·인수·작업 폴더 속성은 [Microsoft 문서](https://learn.microsoft.com/en-us/troubleshoot/windows-client/admin-development/create-desktop-shortcut-with-wsh)를 참고했으며, 실행 파일 표식은 [검은사막 공식 설치 안내](https://www.kr.playblackdesert.com/ko-KR/Wiki?wikiNo=288)를 기준으로 사용합니다. 이번 추가 기능은 요청에 따라 실행 검증하지 않았습니다.

## 온라인 폰트 미리보기·다운로드

게임용 **온라인 폰트** 탭은 TTF가 제공되는 폰트만 표시합니다. 동봉 자료로 TTF가 확인된 항목은 즉시 보이고, OTF만 확인되었거나 처음 보는 항목은 별도의 작은 파일 목록 정보로 TTF 제공 여부를 확인한 뒤 표시합니다. TTF가 없거나 아직 확인하지 못한 항목은 숨깁니다. 한 번에 최대 2개씩 확인하며 실제 폰트 파일은 내려받지 않습니다. 확인 결과는 7일 동안 사용자 설정 옆의 `online-font-ttf-assets.json`에 보관하고, 인터넷 오류는 ‘TTF 없음’으로 저장하지 않습니다. 숨긴 탭에서는 다음 확인을 시작하지 않습니다. 원본 공개 목록에서 삭제된 항목은 기존 자동 갱신에 따라 제외됩니다.

게임용 내 PC 목록도 실제 TTF 파일만 표시합니다. 다운로드와 게임 적용 단계에서 확장자뿐 아니라 TrueType 헤더·글리프 표를 확인하여, OTF를 `.ttf`로 이름만 바꾼 파일이나 폰트 컬렉션을 적용하지 않습니다. OTF를 TTF로 변환하지 않습니다. 이미 다운로드한 OTF 파일은 지우지 않으며 초상화 텍스트 편집에서 계속 사용할 수 있습니다. 게임 적용은 확인된 TTF를 `prestringtable/font/pearl.ttf`로 복사하고 기존 파일을 백업하는 방식입니다. 이번 변경은 요청에 따라 실행 검증하지 않았습니다.

폰트 변경 창의 **온라인 폰트** 탭 또는 텍스트 편집창의 폰트 파일 버튼 옆에 있는 **온라인 폰트**를 누릅니다.

1. 왼쪽 목록에서 폰트 이름을 검색하고 선택하면 오른쪽에 카드형 미리보기가 표시됩니다. 화면 구성은 기존처럼 목록과 선택한 폰트의 카드로 유지합니다.
2. 굵기를 골라 **검은사막 너무 좋아!** 문장을 미리 봅니다. 문구는 고정이며 입력란은 없습니다. 밝은 배경·어두운 배경과 검정·흰색·금색·하늘색 글자를 비교할 수 있습니다. 문장은 항상 한 줄이며 카드 너비에 맞춰 축소됩니다.
3. 게임용 폰트 변경 창에서는 **다운로드**를 눌러 선택한 굵기의 TTF 파일을 받아 보관합니다. 초상화 텍스트 편집용 선택창에서는 별도 다운로드 버튼 없이 **이 폰트 선택** 버튼 하나를 사용하며, TTF·OTF를 계속 지원합니다. 다른 굵기는 각각 별도로 받습니다.
4. 폰트 변경 창에서는 다운로드가 끝난 현재 굵기를 하단의 **폰트 적용**으로 게임에 반영합니다. 텍스트 편집창의 별도 선택창에서는 **이 폰트 선택**을 누르면 필요한 파일을 다운로드하고, 완료되면 창을 닫고 현재 텍스트 박스에 바로 적용합니다. 이미 받은 파일은 다운로드 없이 바로 선택합니다. 다운로드 중에는 버튼을 비활성화하고 진행 상태를 표시합니다. 실패하면 선택창에 남아 다시 시도할 수 있으며, 다운로드 중 다른 폰트나 굵기를 선택하거나 창을 닫으면 이전 요청이 뒤늦게 적용되지 않습니다. 이번 변경은 요청에 따라 실행 검증하지 않았습니다.

현재 목록의 **429개 폰트, 굵기별 727종**을 실제 폰트로 미리 그린 투명 PNG 이미지로 동봉했습니다. 동봉 이미지 전체는 약 **6.7MB**이며 실제 폰트 파일은 추가로 동봉하지 않습니다. 같은 이미지를 색상만 바꾸어 네 카드에 사용합니다. 지원하지 않는 문자는 기본 글꼴로 표시하고 안내하며, 한글을 지원하지 않는 폰트에는 해당 폰트의 영문·숫자 예시를 함께 표시합니다.

미리보기 이미지와 굵기 목록은 프로그램 리소스에서 바로 읽으므로 현재 동봉 목록을 미리 볼 때 인터넷 연결이나 폰트 다운로드가 필요하지 않습니다. 처음 보는 폰트도 같은 방식으로 표시합니다. 화면에 필요한 일부 이미지만 메모리에서 재사용합니다. 새 폰트에 대해 사용자가 생성한 이미지는 아래 사용자 저장 폴더에 보관하며, 동봉 이미지를 복제하지 않습니다. **미리보기 다시 불러오기**는 이미지를 다시 읽습니다. 실제 TTF·OTF 다운로드와 목록 새로고침은 인터넷 연결이 필요합니다.

**다운로드한 폰트** 필터로 보관한 폰트를 모아 볼 수 있습니다. 받은 폰트는 기존 폰트 목록에도 이름과 굵기로 표시하며, 다음 실행의 텍스트 편집창에서도 선택할 수 있습니다. Windows 전체에 폰트를 설치하지는 않습니다. 다운로드만 하고 창을 닫아도 받은 파일은 보관합니다.

폰트 파일은 `%LOCALAPPDATA%/JHHorizon/PortraitManager/fonts`에 보관하므로 프로그램 폴더나 EXE를 바꿔도 같은 Windows 사용자 계정에서 계속 사용할 수 있습니다. 글자 편집 설정에는 보관한 파일 경로를 기록합니다. 이 폴더의 다운로드한 파일은 자동으로 지우지 않습니다. 다운로드는 QtNetwork로 처리하며 개별 파일 최대 40MiB, 요청 시간 제한과 GitHub/CDN 대체 경로를 적용합니다. 받은 파일 크기는 화면에 표시합니다.

폰트 목록은 [Fonts Archive](https://github.com/fonts-archive)의 폰트 가운데 [Korean Vibe Fonts 공개 목록](https://github.com/seulkikaang/korean-vibe-fonts/blob/main/references/fonts_archive_commercial.json)에 수록된 항목을 사용합니다. 온라인 폰트 창을 열면 저장된 목록과 동봉 이미지를 먼저 표시하고, 백그라운드에서 이 공개 목록의 최신판을 자동으로 확인합니다. 창이 열려 있는 동안에도 5분마다 다시 확인합니다. 최신 목록으로 전체 목록을 교체하므로 빠진 항목은 자동으로 제외되고 새 항목은 추가됩니다. 선택 중인 폰트가 제외되면 선택과 다운로드 작업도 해제합니다. 인터넷 연결이나 응답에 문제가 있으면 마지막으로 저장한 목록을 유지하고 그 상태를 표시하며 다음 주기에 다시 시도합니다. **목록 새로고침**으로 즉시 확인할 수도 있습니다. 목록을 저장하지 못하더라도 이번에 받은 최신 목록은 현재 창에 반영합니다. 새 폰트는 이 공개 목록에 등록되어야 자동으로 추가됩니다. npm이나 배포처에 등록된 모든 폰트를 직접 감지하는 방식은 아닙니다. 새로 등록된 폰트에 완성된 미리보기가 없으면 **“새로운 폰트 N개가 추가되었습니다. 미리보기를 만들까요?”** 팝업을 표시합니다. **미리보기 만들기**를 수락했을 때만 생성 작업을 시작하며, **나중에**를 누르면 작업하지 않습니다. 같은 창에서 5분마다 다시 묻지는 않으며, 다음에 창을 열면 아직 만들지 않은 항목을 다시 안내합니다. 아래 **미리보기 만들기** 버튼으로 나중에 시작하거나 실패한 항목을 다시 시도할 수도 있습니다.

생성 작업은 제공되는 굵기를 차례로 처리하며 폰트 개수·현재 이름·굵기와 취소 버튼을 진행 창에 표시합니다. 생성이 끝난 이미지는 바로 카드에 반영합니다. 취소하거나 일부 폰트가 실패해도 이미 완성된 이미지는 유지하고, 다시 시작할 때 재사용합니다. 일부 굵기만 만든 폰트는 이후에도 남은 미리보기 생성 대상으로 표시됩니다. 생성하지 않아도 폰트의 다운로드 기능은 사용할 수 있습니다.

생성할 때는 실제 TTF·OTF 데이터를 인터넷에서 메모리로 받아 Qt의 별도 작업 스레드에서 고정 문구를 이미지로 그립니다. 폰트를 Windows나 앱의 폰트 목록에 설치하지 않고, 생성용 폰트 파일도 디스크에 보관하지 않습니다. 이미 영구 다운로드한 폰트가 있으면 그 파일을 사용할 수 있습니다. 완성된 PNG와 작은 색인 파일만 `%LOCALAPPDATA%/JHHorizon/PortraitManager/font-previews`에 저장하므로 EXE를 교체하거나 다음에 프로그램을 실행해도 같은 Windows 사용자 계정에서 재사용합니다. 원래의 영구 다운로드 폴더 `fonts`와 구분됩니다. 생성 작업에는 인터넷 전송 시간이 필요하며, 한 번 만든 이미지를 보는 작업에는 추가 다운로드가 필요하지 않습니다.

**배포처 · 이용 조건**은 라이선스와 원래 배포처 링크가 적힌 저장소 페이지를 엽니다. 폰트별 출처와 파일 주소는 다운로드 폴더의 작은 JSON 파일에도 보관합니다. 각 폰트 파일의 이용 조건은 원래 배포자의 조건을 따릅니다.

미리보기에는 기본 Qt 이미지 기능만 사용합니다. QtWebEngine과 npm 실행 환경은 필요하지 않습니다. EXE 빌드 시 기존처럼 **resources 폴더 전체**를 포함해야 하며 `font_previews.json`, `font_previews/` 이미지 폴더도 함께 넣습니다. 다운로드한 폰트 파일은 EXE에 넣지 않습니다. EXE 빌드는 이번 변경에서 수행하지 않았습니다. 이전 버전의 `font-preview-cache`는 사용하지 않으며 해당 임시 폴더를 지워도 영구 다운로드한 `fonts` 폴더에는 영향을 주지 않습니다.

## 백업과 복원

교체 대상 파일과 같은 위치의 `backup` 폴더에 기존 파일을 복사합니다. 파일명에는 날짜·시간·고유 식별자가 붙습니다. 새 파일을 임시 파일에 먼저 복사하고, 원본 백업이 성공한 다음 대상을 교체합니다. 같은 파일끼리의 교체는 거부합니다.

복원하려면 프로그램을 닫고 백업 파일을 원래 폴더로 복사한 뒤, 백업에 추가된 날짜·시간·식별자를 제거해 원래 파일명으로 되돌립니다. 폰트의 원래 파일명은 `pearl.ttf`입니다. 복원 전 현재 파일도 별도로 보관할 수 있습니다.

## 초상화 목록 로딩

폴더의 파일 이름과 수정 정보는 백그라운드에서 먼저 읽습니다. 이미지는 최대 3개의 작업에서 처리하며, 화면에 보이는 카드와 다음 두 줄을 우선 준비합니다. 검색하거나 스크롤하면 그 위치의 파일을 앞으로 옮기고, 선택한 사진의 큰 미리보기에는 더 높은 우선순위를 줍니다. 아직 준비되지 않은 카드에는 자리 표시만 보이고, 손상되었거나 허용 크기를 넘는 BMP는 제외합니다.

BMP 검사와 RGB 변환은 한 번의 파일 읽기에서 처리합니다. 목록은 사진마다 위젯을 만드는 대신 `QListView`에서 보이는 카드를 그리며, 준비된 이미지를 소량씩 화면에 반영합니다. 파일 읽기·축소·저장된 텍스트 합성·썸네일 PNG 저장은 작업 스레드에서 처리하고, 화면용 `QPixmap`과 위젯 갱신은 UI 스레드에서 처리합니다. 폴더·선택·텍스트 설정을 바꾼 뒤 도착한 이전 작업 결과는 반영하지 않습니다.

96×96 썸네일은 설정 파일 옆 `portrait-thumbnail-cache`에 저장해 다음 실행에도 재사용합니다. 기본 경로는 `%LOCALAPPDATA%/JHHorizon/PortraitManager/portrait-thumbnail-cache`입니다. 파일 경로·크기·수정 시각·텍스트 설정으로 구분하므로 변경된 사진이나 편집 결과만 새로 만들며, 캐시가 없거나 손상되면 원본에서 다시 생성합니다. 캐시는 시작 시와 일정 처리 간격마다 오래된 항목부터 정리해 약 128 MiB 이내로 유지합니다. 이 폴더를 지워도 원본과 텍스트 설정은 남습니다. 캐시는 실행 후 사용자 저장 공간에 생기며 EXE에 포함하지 않습니다.

첫 실행이나 새 사진은 생성 시간이 필요하고, 다음 실행부터 저장된 작은 썸네일을 사용합니다. 원본 사진을 클릭한 큰 미리보기는 별도로 읽습니다. 텍스트 편집창은 준비된 원본 이미지를 재사용하며, 초상화 교체의 파일 쓰기·백업은 기존 방식을 유지합니다. 이번 변경은 실행·성능 측정을 하지 않았으며 실제 확인은 사용자가 진행합니다.

## 초상화에 텍스트 넣기

편집창 오른쪽은 **텍스트 박스**(목록·추가·삭제), **선택한 텍스트 설정**(내용·폰트·글자 스타일), **박스 설정**(배경색·불투명도·모서리 둥글기)의 세 영역으로 나뉩니다. 텍스트 입력 영역이 남는 세로 공간을 채우며, 텍스트가 박스 밖으로 잘릴 때 별도 안내 문구를 표시하지 않습니다.

1. 새 초상화를 선택합니다.
2. 새 초상화를 클릭하면 미리보기 사진 안쪽 오른쪽 위에 나타나는 **연필 아이콘**을 누릅니다. 사진을 선택하지 않았거나 검색·폴더 변경으로 선택이 해제되면 아이콘은 숨겨집니다. 미리보기를 더블 클릭해도 편집창이 열립니다. 아이콘은 화면에만 표시하며 저장하거나 교체할 이미지에는 포함되지 않습니다.
3. 사진 위의 텍스트 박스를 **더블 클릭**해 그 자리에서 내용을 입력할 수 있습니다. 기존 내용을 선택한 상태로 열리므로 바로 새 이름을 쓰면 됩니다. Enter는 줄바꿈, Ctrl+Enter 또는 박스 밖 클릭은 입력 완료, Esc는 직접 입력하기 전 내용으로 되돌리기입니다. 오른쪽 내용 입력란과 박스 목록도 함께 갱신됩니다. 오른쪽 입력란에서도 계속 편집할 수 있습니다. **+ 추가**, **삭제**로 여러 텍스트 박스를 관리합니다.
4. 사진 위의 박스 안쪽을 드래그해 위치를 옮깁니다. **Shift를 누른 채 드래그**하면 다른 박스나 사진의 좌우·위아래 끝과 가로·세로 중심 근처에서 위치를 맞춥니다. 맞춰진 축은 분홍색 안내선으로 표시하며, 마우스나 Shift를 놓으면 안내선이 사라집니다. 안내선은 저장 이미지에 포함되지 않습니다. 박스를 선택하면 테두리에 흰색 조절점이 표시됩니다. 모서리 조절점을 끌어 가로·세로 크기를 함께 바꾸거나, 변 가운데 조절점을 끌어 한 방향으로 크기를 조절합니다. 방향키로 1픽셀, Shift+방향키로 10픽셀씩 이동할 수도 있습니다.
5. 폰트·크기·정렬·글자색과 글자 불투명도를 조절합니다. **굵게·기울임·진하게·그림자**는 카드 전체를 눌러 각각 켜고 끄며, 켜진 카드는 남색으로 표시합니다. **진하게**는 글자 획을 추가로 두껍게 하고, **그림자**는 글자 뒤에 어두운 그림자를 더합니다. 여러 효과를 함께 적용할 수 있습니다. **폰트 파일 불러오기**로 TTF·OTF 파일도 사용할 수 있습니다.
6. 박스 색상과 불투명도·모서리 둥글기를 조절합니다. 불투명도 **0%는 완전 투명**, **100%는 완전 불투명**입니다. 글자와 박스의 불투명도는 독립적입니다. 박스 크기와 위치는 사진 위에서 직접 조절하며, 너비·안쪽 여백·위치의 숫자 입력은 표시하지 않습니다. 글자 크기는 별도로 유지됩니다.
7. **미리보기에 적용**을 누르면 새 초상화 미리보기와 썸네일에 편집 결과가 표시됩니다. 이후 **초상화 교체**를 눌러 게임 초상화에 적용합니다. 기존 게임 초상화는 자동 백업하며 선택한 새 사진 원본은 보존합니다.

편집창의 **BMP로 따로 저장**으로 게임에 적용하기 전에 별도 파일을 저장할 수 있습니다. 실제 원본 이미지의 해상도를 유지하는 RGB BMP로 저장하며, 선택 테두리는 출력에 포함되지 않습니다. 기존 파일에 저장하면 `backup`에 이전 파일을 보관합니다.

**미리보기에 적용**하면 사진별 편집 내용과 최근 박스 설정을 설정 파일에 자동 저장합니다. 같은 원본 사진을 다시 편집하면 내용·위치·박스 크기·폰트·색상·글자 효과를 복원하며, 프로그램을 종료했다가 실행해도 유지됩니다. 새 초상화를 편집하면 최근 설정의 박스와 글자 스타일을 가져오고 내용은 비워두므로 이름만 입력할 수 있습니다. 크기가 다른 사진에서는 박스 위치와 크기를 사진 비율에 맞춰 조정하며 글자 크기 설정은 유지합니다.

기존에 따로 편집한 사진은 그 사진의 설정을 우선 복원합니다. 편집창 아래 **최근 설정 불러오기**를 누르면 최근 설정을 사용한 초상화의 미리보기 카드 목록을 엽니다. 선택 안내 문구는 가운데 정렬로 표시합니다. 카드를 선택하고 **설정 불러오기**를 누르거나 더블 클릭하면 해당 박스·폰트·색상·효과를 현재 초상화에 가져옵니다. 사진은 바꾸지 않고 입력 내용은 비우므로 새 이름을 바로 입력할 수 있습니다. 선택창에서 취소하면 현재 편집 설정을 유지합니다.

설정 기록은 **미리보기에 적용**할 때 저장하며, 이름·입력 내용·박스 식별자만 달라진 경우는 같은 설정으로 묶습니다. 박스 개수와 순서·위치·크기, 글꼴·글자 크기·정렬·색상·불투명도·효과, 박스 색상·불투명도·여백·둥글기를 비교합니다. 위치·크기는 사진 비율을 기준으로 비교합니다. 같은 설정을 다시 사용하면 최근 사용 순서만 갱신하며, 대표 사진과 사진에 보이는 내용은 처음 저장한 것을 유지합니다. 다른 설정을 적용하면 새 항목으로 남깁니다. 목록은 최근 사용한 설정 순서로 표시합니다.

대표 미리보기는 `%LOCALAPPDATA%/JHHorizon/PortraitManager/portrait-preset-previews`에 작은 PNG로 보관하고 설정 기록은 기존 `settings.json`에 저장하므로 다음 실행과 EXE 교체 후에도 유지됩니다. 같은 사진에서 설정을 바꾸더라도 이전 설정의 대표 미리보기를 보존합니다. 이전 버전의 사진별 저장 기록도 불러올 때 중복을 묶어 사용하며, 그 버전에서 이미 덮어쓴 과거 설정까지 복원하지는 않습니다. 기존 기록의 원본 사진이 사라지거나 변경되어 대표 이미지를 만들 수 없으면 **미리보기 없음**으로 표시하고 설정 자체는 선택할 수 있습니다.

원본 사진 파일이 변경되면 이전 사진별 편집 내용은 복원하지 않습니다. **취소**한 편집 변경은 설정 기록에 저장하지 않습니다.

파일로도 결과를 보관하려면 별도 BMP 저장이나 초상화 교체를 완료하세요. BMP는 글자와 사진을 합친 이미지입니다. 개별 박스로 다시 편집할 설정은 프로그램의 설정 파일에 보관합니다. 불러온 폰트 파일도 경로를 기억하므로 원래 위치에 파일을 유지하면 다음 실행에 다시 불러옵니다.

박스는 사진 영역 안에서 이동하고 크기를 조절합니다. 텍스트는 박스 높이에 관계없이 항상 위아래 가운데에 배치됩니다. 텍스트 전체 높이가 박스보다 크더라도 중앙 정렬을 유지하며 위아래의 넘친 부분을 잘라 표시합니다. 조절점을 끌어 박스를 키우거나 글자 크기를 줄여 조정할 수 있습니다.

미리보기와 저장은 같은 텍스트 렌더링 함수를 사용합니다. 화면에서 축소해 보여도 위치·크기 설정은 실제 원본 픽셀을 기준으로 계산합니다. 구현에는 Qt의 [Graphics Item](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QGraphicsItem.html)과 텍스트 문서 렌더링을 사용합니다.

## 여러 초상화에 같은 텍스트 설정 적용

텍스트 편집창 아래 **여러 초상화에 적용**을 누르면 현재 새 초상화 폴더의 사진을 선택하는 창이 열립니다. 사진을 클릭해 여러 장을 선택하거나 해제하고, 한글 이름 검색으로 대상을 좁힐 수 있습니다. 검색해도 다른 검색 결과에서 선택한 사진은 유지되며, 선택 개수는 숨겨진 선택까지 포함합니다. **검색 결과 전체 선택**은 현재 보이는 검색 결과를 선택에 추가하고 **선택 해제**는 모든 선택을 해제합니다. 선택한 카드에는 체크 표시가 나타납니다.

**선택한 초상화에 적용**하면 현재 편집창에 있는 모든 박스의 위치·크기·폰트·글자 크기·정렬·색상·불투명도·효과·박스 배경 설정을 함께 적용합니다. 크기가 다른 원본에서는 위치와 박스 크기를 사진 비율에 맞추며 글자 크기는 유지합니다. 박스 개수가 같은 사진은 사진별 기존 내용을 유지합니다. 개수가 다르면 **현재 설정으로 덮어쓰고 내용은 비운다**는 팝업에서 확인을 받은 후 현재 박스 개수와 설정을 적용합니다. 설정이 없던 사진도 빈 내용의 박스로 시작합니다. 내용이 비어 있어도 배경색과 불투명도가 설정된 박스는 새 초상화 목록의 썸네일과 큰 미리보기에 표시하며, 저장·교체 결과에도 동일하게 반영합니다. 배경 불투명도가 0%이면 박스가 보이지 않는 것은 정상이며, 위치·크기·폰트 설정은 편집창에서 복원합니다. 팝업에서 취소하면 선택한 사진 모두에 아무 설정도 적용하지 않습니다.

적용 준비는 백그라운드에서 진행하며 진행률을 표시합니다. 준비 중 취소해도 설정은 저장하지 않습니다. 완료할 때 읽을 수 있고 원본이 그대로인 사진의 설정을 한 번에 저장하고, 적용한 사진의 썸네일만 백그라운드에서 갱신합니다. 손상되었거나 변경된 사진은 제외하고 개수를 알립니다. 새 설정은 다음 실행에도 복원됩니다. 기존 최근 설정 기록은 같은 설정의 첫 대표 초상화를 계속 유지합니다.

일괄 적용은 사진별 편집 설정과 미리보기에 적용합니다. 새 사진 원본이나 게임 초상화 BMP를 덮어쓰지 않습니다. 실제 게임 반영은 기존 **초상화 교체** 기능을 사용합니다. 일괄 적용을 완료한 뒤 편집창에서 취소하더라도 이미 명시적으로 적용한 여러 사진의 설정은 유지됩니다. 이번 추가 기능은 요청에 따라 실행 검증하지 않았습니다.

## 전환 관련 수정

- `QDesktopWidget` 대신 Qt 6의 화면 API를 사용하고, 열거형과 `exec()` 호출을 변경했습니다.
- 창 생성 중 번역에 먼저 접근하던 초기화 순서를 수정했습니다.
- 폰트 파일 경로와 미리보기용 `QFont` 객체를 분리했습니다.
- 잘못된 경고 처리 코드가 폰트 목록을 바꾸던 문제를 제거했습니다.
- 언어 버튼을 다시 눌러도 선택 언어가 임의로 뒤집히지 않도록 했습니다.
- 검색으로 보이지 않게 된 선택을 초기화하여 숨은 파일을 교체하지 않도록 했습니다.
- 이미지 핸들을 닫고, Qt 이미지가 바이트 버퍼를 직접 소유하도록 했습니다.
- Windows 설정과 별도로 프로그램에서 라이트·다크 모드를 선택하고, 배경과 글자색을 공통 팔레트로 적용합니다.

Qt 6 API 변경은 [Qt 공식 이전 안내](https://doc.qt.io/qtforpython-6/faq/porting_from2.html)를 참고했습니다.
