JHnode 단일 EXE 사용 안내

JHnode.exe 하나만으로 실행할 수 있습니다.
Python이나 PySide6를 따로 설치하거나 _internal 폴더를 옆에 둘 필요가 없습니다.
Windows 10 / Windows 11 64비트용입니다.

실행할 때 필요한 구성요소를 Windows 임시 폴더에 풀기 때문에
폴더형보다 창이 열리기까지 시간이 조금 더 걸릴 수 있습니다.
프로그램을 정상 종료하면 이 임시 구성요소는 자동 정리됩니다.

설정·최근 편집·다운로드한 폰트는 임시 폴더가 아닌 기존 사용자 경로에 저장됩니다.
%LOCALAPPDATA%\JHHorizon\PortraitManager
기존 버전과 같은 계정에서 실행하면 저장한 설정을 이어서 사용합니다.

처음에는 현재 초상화와 새 초상화 폴더를 선택하세요.
초상화를 교체하면 원본은 기존 초상화 폴더의 Backup 폴더에 보관됩니다.
폰트 변경은 프로그램 하단의 Aa 아이콘을 누릅니다.
눈누 폰트 찾기를 누르면 브라우저가 열립니다. 이용 조건 확인 후 받은 폰트는 폰트 추가로 불러오세요.

함께 제공하는 고지문과 라이선스 문서는 배포 시 함께 보관하세요.
이 문서들은 실행에 필요한 외부 프로그램 구성요소는 아닙니다.
라이선스 문서는 EXE 내부에도 포함되어 있습니다.
