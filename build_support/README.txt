JHnode 사용 안내

1. ZIP 파일을 원하는 폴더에 모두 압축 해제합니다.
2. JHnode 폴더의 JHnode.exe를 실행합니다.
3. 현재 초상화와 새 초상화 폴더를 선택해 사용합니다.
4. 폰트 변경은 프로그램 하단의 Aa 아이콘을 누릅니다.

Python과 별도 pip 패키지 설치는 필요하지 않습니다.
JHnode.exe 옆의 _internal 폴더도 반드시 함께 보관하세요.
실행 파일만 다른 곳으로 옮기면 실행되지 않습니다.

지원 대상: Windows 10 / Windows 11 64비트.
온라인 폰트 목록 갱신과 폰트 다운로드에는 인터넷 연결이 필요합니다.
설정·최근 편집·다운로드한 폰트는 사용자별로 저장됩니다.
이전 버전과의 호환을 위해 저장 위치는 아래 경로를 유지합니다.
%LOCALAPPDATA%\JHHorizon\PortraitManager

초상화를 교체하면 원본은 기존 초상화 폴더의 Backup 폴더에 보관됩니다.
게임 폰트는 선택한 검은사막 설치 위치의 prestringtable\font\pearl.ttf에 적용됩니다.
설정에서 설치 위치를 다시 지정할 수 있습니다.

창이 화면보다 크면 Windows 화면 배율 또는 해상도를 확인하세요.
현재 기본 창 크기는 기존 830×910을 유지합니다.

다른 PC에 직접 설치한 폰트는 자동으로 전달되지 않습니다.
다운로드한 폰트를 포함해 각 폰트의 이용 조건은 해당 제작자의 안내를 따릅니다.
동봉 구성요소의 고지문은 THIRD-PARTY-NOTICES.txt와 _internal\licenses에 있습니다.
